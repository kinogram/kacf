# KACF（Kinogram AutoCoding Framework）

语言：[English (Default)](README.md) | **简体中文-母语**

KACF 是一个面向真实开发场景的 AI 编程应用。
你只需要用自然语言描述目标，KACF 会自动循环：

`规划 -> 写代码 -> 跑测试 -> 修复 -> 继续迭代`

当前模式：**Web UI**。

## 先选版本

- `personal`：单用户，轻量
- `multi-user`：多用户 + 管理员面板（多人共用时推荐）

## 快速开始（小白友好）

### 1）下载并运行

请在终端里运行（不要双击文件）。

例如：

```bash
cd Downloads
./kacf-multi-user-v1.1.0-linux-amd64
# 或
./kacf-multi-user-v1.1.0-linux-arm64
# 或
./kacf-multi-user-v1.1.0-windows-amd64.exe
```

也可以直接从源码运行：

```bash
cargo run --release
```

### 2）打开页面

浏览器访问：

`http://localhost:8080`

### 3）首次使用

- 先初始化管理员账号
- 再让其他用户注册/登录
- 默认只允许主流邮箱注册

### 4）开始使用

- 在页面中新建项目
- 用自然语言描述你的需求
- 点击运行，KACF 会自动迭代执行

## 运行前必读

- **请在终端中运行程序，不要双击可执行文件。**
- 如果你已经双击过，请先结束旧进程，否则可能出现端口占用。
- 刚启动时终端可能暂时没输出，但服务可能已经在监听。
- 只要终端没有报错退出，直接打开 `http://localhost:8080` 即可。
- 需要停止程序时，在终端按 `Ctrl-C`。

## `multi-user` 版包含什么

- 角色：`Admin / User / Guest`
- 访客模式：无需注册，可读不可改
- 管理员面板：管理用户、封禁、通知、重置密码、审计日志
- 账户中心：修改昵称/密码/用户名/邮箱、切换登录方式
- 数据隔离：每个用户独立 `ui_cache/projects/workspaces`

## 常见问题（简单版）

- 页面打不开：
  - 先确认终端里的程序还在运行
  - 再确认访问的是 `http://localhost:8080`
- 提示“端口被占用”：
  - 说明 8080 已被其他进程占用，结束后重启 KACF
- 双击运行后异常：
  - 结束旧进程，改为终端运行
